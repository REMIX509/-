使用說明
  1. 將 QR Code 投影到螢幕或列印出來放在簽到處
  2. 與會人員用手機掃描 QR Code
  3. 進入簽到頁面後，從下拉選單選擇姓名
  4. 確認個人資訊與便當選擇後，點擊「確認簽到」
  5. 管理員可在「名單」和「統計」頁籤即時查看簽到狀況
